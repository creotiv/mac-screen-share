  1. In BetterDisplay, create one virtual display per device (e.g. 1920×1200 for a tablet, 2400×1080 for a phone).
  2. Click + Add screen once per virtual display, then choose Entire screen → that display.
  3. Open each screen's link on its device. Each device remembers its screen, so it reconnects to the same one next time.
